backend/Dockerfile (Laravel 11 Multi-Stage) php:8.4-cli-alpine
# Stage 1: Builder (Cache Composer Layer)
FROM php:8.4-cli AS builder
COPY --from=composer:2.8 /usr/bin/composer /usr/bin/composer
WORKDIR /app
# Salin manifest DAHULU agar layer composer ter-cache
COPY composer.json composer.lock ./
RUN composer install --no-dev --no-scripts --no-autoloader
COPY . .
RUN composer dump-autoload --optimize --no-dev

# Stage 2: Runtime (Minimal Alpine Image)
FROM php:8.4-cli-alpine AS runtime
RUN apk add --no-cache libzip curl && docker-php-ext-install bcmath pcntl zip
WORKDIR /app
COPY --from=builder /app .
# Non-root user
RUN addgroup -S appgroup && adduser -S appuser -G appgroup
USER appuser
EXPOSE 8000
frontend/Dockerfile (Vue 3 Multi-Stage) nginx:1.27-alpine
# Stage 1: Builder (Node.js Build)
FROM node:20.19-alpine AS builder
WORKDIR /app
# Salin package.json DAHULU agar layer npm ter-cache
COPY package.json package-lock.json ./
RUN npm ci --prefer-offline
COPY . .
RUN npm run build

# Stage 2: Runtime (Nginx Serving dist/)
FROM nginx:1.27-alpine AS runtime
# Salin HANYA hasil build; node_modules TIDAK ikut
COPY --from=builder /app/dist /usr/share/nginx/html
# SPA Routing fallback ke index.html
RUN echo 'server { listen 80; ... try_files $uri /index.html; }'
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]

Kesesuaian dengan Seluruh Kriteria Soal 5:

✓ Versi Jelas (Bukan latest): Menggunakan php:8.4-cli-alpine, composer:2.8, node:20.19-alpine, dan nginx:1.27-alpine.
✓ Layer Cache: composer.json/lock dan package.json/lock disalin dan diinstall sebelum source code aplikasi disalin.
✓ Multi-Stage Frontend: Node 20 membangun aplikasi, Nginx menyajikan dist/. Image akhir bebas dari node_modules.
✓ Berkas .dockerignore: Tersedia di backend/.dockerignore dan frontend/.dockerignore (mengabaikan node_modules, vendor, .git, .env).
✓ Bebas Rahasia: Tidak ada hardcoded credentials/key di dalam Dockerfile mana pun; kredensial disuplai runtime melalui environment.
